## AI-Assisted Development Reflection

- **How I used AI:** I used GitHub Copilot to help me build my flashcard study app. I worked through the project one feature at a time instead of trying to build everything at once.

- **What AI helped me with:** Copilot helped me write the code for creating, editing, and deleting decks and flashcards, along with the study features, search, and LocalStorage. It definitely helped me get through the assignment faster.

- **Where AI got it wrong:** Copilot introduced a bug that stopped me from creating new decks. The problem was with an event listener passing a click event into a function that was expecting a deck object. I also had an issue with my CSS because the `[hidden]` selector was nested incorrectly.

- **How I tested the code:** I tested each feature as I went instead of assuming the code worked. I created, renamed, and deleted decks and cards, tested the study controls and search, and refreshed the page to make sure my data was still there. When something didn't work, I went back and fixed it before moving on.

- **What I learned:** AI can help me write code faster, but that doesn't mean the code is always right. I still need to understand what it's doing and be able to recognize when something isn't working. This assignment showed me that debugging is just as important as getting the code written in the first place.
